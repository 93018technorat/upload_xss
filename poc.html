Security PoC — postMessage DOM XSS on www.ebay.com

Click the button. It opens https://www.ebay.com/buyer-preferences/test in a focused popup window and sends a cross-origin postMessage. The page's listener has no origin check and renders the type via dangerouslySetInnerHTML, so the payload executes in the www.ebay.com origin.

A popup window (not a background tab) opens so the alert() is not suppressed. Within ~1s an alert("XSS in www.ebay.com") appears in that window. If a browser still blocks the alert, the popup's tab/window title also changes to XSSED-www.ebay.com as backup proof.
