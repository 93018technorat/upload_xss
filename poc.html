Security PoC — postMessage DOM XSS on www.ebay.com

One click opens https://www.ebay.com/buyer-preferences/test and sends a cross-origin postMessage. The page's message listener has no origin check and renders the type field via dangerouslySetInnerHTML, so the payload executes in the www.ebay.com origin.

Expected: a popup loads eBay's "Test Page", then an alert() showing www.ebay.com fires inside that popup (arbitrary JS executed in eBay's origin, delivered cross-origin from this page). The one click is only needed so the browser allows the popup.
